Figma2AE documentation

Everything you need to install Figma2AE, send your first design to After Effects, and get the most out of it.

Requirements

  • macOS (Apple Silicon or Intel) — any version your After Effects supports.
  • Adobe After Effects 2023 (23.0) or newer. Per-character text styles (several fonts/colours in one text layer) need 24.3 or newer.
  • The Figma desktop app. Plugins installed from a manifest file run in the desktop app.
  • The fonts used in your design installed on your Mac (otherwise After Effects substitutes them).

Install

Figma2AE has two parts that talk to each other on your computer: a panel inside After Effects and a plugin inside Figma. Install both.

Download both files from the latest release:

Figma2AE-ae-extension.zip and Figma2AE-figma-plugin.zip

Step 1 — Install the After Effects panel

  1. Double-click Figma2AE-ae-extension.zip to unzip it.
  2. Open Terminal (Applications ▸ Utilities ▸ Terminal), type cd (with a space), drag the unzipped folder into the Terminal window, and press Return.
  3. Run the installer: 
    sh install.sh
    It copies the panel into ~/Library/Application Support/Adobe/CEP/extensions/ and enables Adobe's setting for loading extensions that aren't distributed through Adobe Exchange.
  4. Quit and reopen After Effects.
  5. Open Window ▸ Extensions ▸ Figma2AE. The panel should say “Listening on :7741”.
  6. Dock the panel anywhere you like. It needs to be open (it can be in a background tab) whenever you sync from Figma.

If Figma2AE doesn't appear under Window ▸ Extensions, see Troubleshooting.

Step 2 — Install the Figma plugin

  1. Unzip Figma2AE-figma-plugin.zip and move the folder somewhere permanent, e.g. your Documents folder. Figma loads the plugin from this folder every time, so don't delete it.
  2. Open the Figma desktop app and any design file.
  3. From the main menu choose Plugins ▸ Development ▸ Import plugin from manifest…
  4. Select figma-plugin/manifest.json inside the unzipped folder.
  5. Run it from Plugins ▸ Development ▸ Figma2AE. Tip: right-click the canvas ▸ Plugins to find it quickly, or use ⌘ / and type “Figma2AE”.

Step 3 — Your first sync

  1. Make sure After Effects is open with the Figma2AE panel visible.
  2. In Figma, open the plugin. The status pill in its top-right corner turns green and shows your After Effects version once it's connected.
  3. Select one or more frames (or any layers) on the canvas.
  4. Press Sync Selection.
  5. In After Effects, a new composition opens for each selected frame, inside a Figma2AE folder in the Project panel.

Everything a sync creates is a single undo step: ⌘ Z in After Effects removes it.

The Figma plugin

  • Status pill — green when connected to After Effects. If it says After Effects not found, open the panel in AE; the plugin reconnects automatically (or press Retry now).
  • Selection — shows what will be sent.
  • Break Apart Layers — how the design is laid out in AE (see below).
  • Advanced — composition and image settings.
  • Sync Selection — sends the selection to After Effects.
  • Export — saves the selection as PNG, SVG, PDF or an AE bundle.
  • Notes — after each sync, expand notes to see anything that was approximated (e.g. a missing font).

Exporting PNG / SVG / PDF

Pick a format next to the Export button and press it:

  • PNG — at the Image scale set under Advanced.
  • SVG — vector, with text converted to outlines.
  • PDF — vector document.
  • AE bundle — a .f2ae.json file you can import into After Effects later (see below).

One selected layer downloads as a single file; several layers download together as a .zip. Export works without After Effects.

Working without a connection

No After Effects on this machine, or handing work to a colleague? Choose AE bundle and press Export. In After Effects, press Import bundle… in the Figma2AE panel and pick the .f2ae.json file. The result is identical to a live sync, images included.

The After Effects panel

  • Status — Listening on :7741 · 1 Figma client means a Figma plugin is connected. Yellow while building.
  • Import bundle… — builds a .f2ae.json exported from the plugin.
  • Activity — the last 20 syncs, with layer counts, timings and any notes.

The panel creates a Figma2AE folder in your project with your comps, a Precomps folder for clipped frames, and an Assets folder for images. Re-syncing the same image reuses the existing footage item.

Known limitations

  • Angular and diamond gradients are approximated as radial; gradients with more than 3 colour stops are approximated with 3.
  • Shadow spread and background blur have no After Effects equivalent and are skipped (you'll see a note).
  • Image adjustments (exposure, contrast…) are not transferred.
  • Skewed text and images lose their skew.
  • Font rendering differs slightly between Figma and After Effects; text can be a pixel or two off.

Tips for best results

  • Name your layers in Figma — names carry over to AE layers and groups.
  • Install the fonts before syncing; otherwise AE substitutes them (the sync notes tell you which).
  • Sync frames to get a comp per frame. Sync individual layers with Destination Active comp to add them to a comp you're already working in.
  • Use Break Apart OFF for complex icons and illustrations; you can still break them apart later in AE.
  • Very large files: sync one frame at a time for the fastest turnaround.

Updating

  1. Download the new zips from the latest release.
  2. After Effects: unzip, run sh install.sh again (it replaces the old version), then restart After Effects.
  3. Figma: unzip and replace the contents of your existing plugin folder (same location), then close and re-run the plugin. If you put it in a new location, import its manifest.json again and remove the old entry under Plugins ▸ Development ▸ Manage plugins in development.

Uninstalling

  • After Effects panel: in the unzipped folder run sh install.sh --uninstall, then restart After Effects.
  • Figma plugin: Plugins ▸ Development ▸ Manage plugins in development ▸ remove Figma2AE, then delete its folder.
  • Optional clean-up: delete ~/Library/Caches/Figma2AE (image cache) and ~/Library/Logs/Figma2AE (logs).

Troubleshooting

“Figma2AE” isn't listed under Window ▸ Extensions

  1. Check your version: After Effects ▸ About After Effects must be 2023 (23.0) or newer.
  2. Run sh install.sh again and make sure it prints Installed to: ….
  3. Fully quit After Effects (⌘ Q) and reopen it — extensions are only discovered at launch.

The plugin says “After Effects not found”

  1. After Effects must be running with the Figma2AE panel open.
  2. In a browser, open http://localhost:7741/health. If you see "ok":true, the panel is listening — press Retry now in the plugin.
  3. If the page doesn't load, check the panel's status line. A security tool or another app using ports 7741–7745 can block it; the panel automatically tries the next port.

“Unable to load code” when opening the Figma plugin

The plugin folder was moved or deleted. Import figma-plugin/manifest.json again from its current location.

“Figma sync failed” in the panel

  1. Expand the entry in the panel's Activity list for details.
  2. Check the log: in Finder press ⇧ ⌘ G and open ~/Library/Logs/Figma2AE/bridge.log.
  3. Make sure you're on the latest release, then open an issue with the log and, if possible, the exported .f2ae.json bundle.

Fonts look different

The sync notes list substituted fonts. Install the exact font family and style on your Mac (the same file Figma uses), restart After Effects, and sync again.

Mixed text styles collapsed into one

Several styles inside one text layer need After Effects 24.3 or newer. On older versions the most-used style is applied to the whole layer.

FAQ & privacy

Does my design get uploaded anywhere?

No. The plugin sends data only to the Figma2AE panel on the same computer (localhost). The panel only accepts connections from your own machine and from the Figma plugin. There is no telemetry.

Why does the installer change an Adobe setting?

After Effects only loads extensions from Adobe Exchange unless PlayerDebugMode is enabled. The installer turns it on so the Figma2AE panel can load. This is the standard way to install independent CEP extensions.

Does it work on Windows?

Not officially. The panel and plugin are cross-platform, but the installer and testing target macOS.

Can I edit the gradients in After Effects?

Yes — select the gradient layer and open Effect Controls ▸ Tritone: Highlights is the start colour, Shadows the end colour, Midtones the middle. The gradient's direction is on the layer's Gradient Fill (Start/End Point).

Is it free?

Yes, free and open source. Contributions and bug reports are welcome on GitHub.

Building from source

Requires Node.js 20 or newer.

git clone https://github.com/JayPrIO/figma2ae.git
cd figma2ae
make install      # install dependencies
make check        # typecheck + full test suite
make build        # build everything into ./dist
make install-ae   # install the AE panel from your build

Then import figma-plugin/manifest.json (or dist/figma-plugin/manifest.json) in Figma. See the README for architecture, debugging and release details.
